# Task log

One file per finished task, named `YYYY-MM-DD-<issue>-<short-slug>.md`
(for example `2026-11-17-1-hn-collector.md`). Never edit another entry; add a new one instead.

Template:

```
# #<issue> <title>

Agent: claude | cursor | codex | human
Date: YYYY-MM-DD

- Did: what changed, in 1 to 3 bullets
- Files: paths touched
- Tests: added or changed, and whether they pass
- Why: the key reasoning or tradeoff
- Next: follow-ups or open questions
```
