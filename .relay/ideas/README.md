# Ideas

Ideas for Pulse and Relay that are not scheduled yet. Revisit them when planning the next round
of work. One file per idea, named `<area>-<short-slug>.md` (for example
`relay-review-fix-loop.md`), so parallel additions never conflict.

Anyone can add an idea: the owner, or an agent that notices something outside its current issue.
To act on an idea, open an issue for it and set its status to `planned` with the issue number.

Template:

```
# <Title>

Area: relay | pulse
Status: new | planned (#<issue>) | done (#<issue>) | dropped
Added: YYYY-MM-DD

- Problem: what is slow, manual, or missing today
- Idea: the proposed change
- Notes: tradeoffs, risks, open questions
```

Keep entries short. When an idea is dropped, say why in Notes instead of deleting the file.
